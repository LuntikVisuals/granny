# Granny

**Granny** — мобильный 2D хоррор-побег (вид сверху) из дома безумной бабушки. Цель — выжить 5 дней, собрать предметы и сбежать, не производя шума.

Есть выбор персонажа (выжившие + антагонисты Бабушка/Дед для мульти), рейтинг и локальный мультиплеер по Wi-Fi.

Вся игра — один `index.html` (canvas + Web Audio). Android — WebView-обёртка с LanBridge.

## Текущий статус (прототип)

- Движение (WASD / стрелки / свайп по экрану)
- Простая карта дома (комнаты)
- Бабушка слышит шум и идёт на него
- При поймке теряется день (до 5)
- Выбор персонажа (влияет на скорость и шум)
- Заглушки рейтинга и LAN

## Структура

Аналогична Windup Wonderland:
- `index.html` — вся игра
- `android/` — WebView + LanBridge / LanRelay
- `.github/workflows/publish.yml` — публикация APK

Следующие шаги: предметы, ключи, ловушки, полный LAN, озвучка, сохранение рейтинга.
