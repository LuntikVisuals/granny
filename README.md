# Granny

**Granny** — мобильный 2D хоррор-побег (вид сверху) из заброшенного дома безумной бабушки. Цель — собрать предметы, решить головоломки и сбежать за 5 дней, не давая ей слышать тебя.

В каждом раунде можно выбрать персонажа (с разными способностями), есть рейтинг и игра по локальной сети (Wi-Fi). Страшно, но без крови: темнота, скрип полов, шаги бабушки, сердцебиение.

Вся игра — один HTML5-файл (`index.html`), интернет не нужен: графика рисуется кодом на canvas, звуки синтезируются Web Audio. Android-версия — нативная обёртка (WebView) вокруг того же файла. Интерфейс на русском.

> Неофициальная бесплатная фан-игра. Без доната и рекламы. Вдохновлена Granny (DVloper). Все права на оригинал принадлежат разработчику.

## Структура (как в Windup Wonderland)

- `index.html` — вся игра (скоро разрастёт)
- `android/` — WebView-обёртка + LAN-мост
- `music/`, `voice/` — аудио
- `.github/workflows/publish.yml` — публикация APK

## Механики (план)

- 5 дней / жизней
- Шум привлекает Бабушку (шаги, падение предметов, двери)
- Предметы, ключи, ловушки, спрятанные места
- Несколько путей побега (дверь, машина, канализация)
- Выбор персонажа с уникальными способностями
- Рейтинг
- LAN-мультиплеер (хост + клиенты в одной сети)
